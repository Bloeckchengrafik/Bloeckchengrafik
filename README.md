### About me

I'm a developer from Germany with a particular weakness for projects that cross the boundary between **software and hardware**.

I try to mostly work with **Java, Kotlin, Rust and TypeScript** because I enjoy systems where strong abstractions, type safety and compile-time guarantees make entire classes of bugs disappear. Less sanity lost, more time for useless-but-fun asides.

Currently, I'm especially interested in:
* 🧩 **Kotlin** — expressive, type-safe application development, interestingly not mobile
* 🦀 **Rust** — async systems, networking and backend tooling
* ⚡ **Embedded & IoT** — software that eventually has to make real hardware do something
* 🐧 **Linux** — because apparently configuring the computer is part of using the computer
* 🔌 **FPGA & digital design** — currently venturing further down the hardware rabbit hole
* 🖥️ **Modern frontend development** — preferably Svelte or Solid over yet another React app
